# Agent Rules

- Arbeite ausschließlich in diesem Repository.
- Arbeite niemals direkt auf `main`.
- Erstelle für jede Aufgabe einen Branch nach dem Muster `agent/<taskname>`.
- Ändere keine Systemdateien außerhalb des Repositories.
- Speichere keine Secrets im Repository.
- Führe nach Änderungen Build und Tests aus.
- Halte Commits klein und sinnvoll.
- Ergänze nach Abschluss einer Aufgabe eine kurze Notiz in `docs/WORKLOG.md`.
