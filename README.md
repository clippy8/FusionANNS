# FusionANNS

Remote Repository für die Entwicklung mit CLion auf einem Ubuntu-Server.

## Ziel
Dieses Repository dient als zentrale Entwicklungsbasis für:
- manuelle Entwicklung in CLion per SSH / Remote Development
- agentische Entwicklung auf dem Server
- MVP-Erstellung und anschließendes Refactoring

## Grundregeln
- Kein direktes Arbeiten auf `main`
- Für jede Aufgabe ein eigener Branch
- Änderungen immer bauen und testen
